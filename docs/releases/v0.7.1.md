临题 v0.7.1 · AI 导题全链路修复与 AI 导题/出题实时进度及错误反馈

- AI 导题全链路修复与长文档分批：修复 DeepSeek 官方接口下长文本导题超时与输出截断问题，支持按题号/段落智能分批识别（单批 3,500 字）、`max_tokens = 8192`、顶层数组与 `{"questions":[...]}` 双格式兼容、`ESSAY` 简答题型识别，以及超长截断响应中已完成题目的自动抢救。
- OCR 与 AI 识别联动：拍照导题、图片导题与扫描版 PDF 在线 OCR 后，若选择「仅 AI 识别」或本地规则解析为 0 题且已配置 AI Key，自动调用 AI 结构化拆题。
- 导题与出题实时进度反馈：首页导题新增分阶段实时进度卡片与模态进度弹窗（提取文本、分批 AI 识别及已识别题数）；AI 主题/仿写/智能刷题新增已用时计时与思考强度提示；材料出题新增提取/OCR/分批生成状态及总体批次进度卡片，校对页支持一键「全部确认」。
- 明确错误原因与 Key 自动保存：细化 HTTP 状态码（401/402/429/5xx 等）、网络超时与空结果的中文诊断提示（自动脱敏 API Key），导题失败保留在首页展示原因卡片并提供「前往 AI 设置」快捷入口；AI 设置页显示「已配置 Key / 未配置 Key」状态徽标并在返回时自动保存已输入的 Key。
