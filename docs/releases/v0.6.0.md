临题 v0.6.0 · 练习续练、设置中心分页与无障碍优化

- 新增练习续练：顺序、错题、收藏、专项、真题等练习会话自动保存，进程被系统回收后首页出现「继续上次练习」卡片，一键回到上次题号；顺序练习同时恢复本轮作答。
- 「我的」改为入口式设置中心：学习统计、外观、练习设置、AI 服务、OCR 识别、数据备份、关于与更新各自独立成页，入口行显示当前配置摘要；AI 与 OCR 配置入口从相关功能页直达对应子页。
- 新增学习统计页：累计答题、正确率、连续学习天数，以及今日答题、待复习错题、练习场次和各题库顺序练习进度。
- 无障碍与触控优化：选项卡向读屏完整播报单选/多选角色与选中状态；答题卡格子播报答对/答错/未做/当前/标记，格子尺寸自适应不小于 48dp；答题底栏字符符号改为矢量图标并扩大点击区；进度条补充语义。
- 交互修正：错题本返回保持来路；倒计时不再引起整屏每秒重组；简答题参考答案跟随字号设置；笔记编辑取消前确认防丢稿；重复提示不再被吞；答对/答错加入轻微触觉反馈。
- 工程升级：Kotlin 2.0.21 与 Compose 编译器插件（强跳过模式）；答题、答题卡、组卷、成绩拆分为独立文件；单元测试与本机代理环境隔离。
